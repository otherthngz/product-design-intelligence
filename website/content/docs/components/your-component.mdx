description: How PDI guidance approaches existing design systems and handoffs.

PDI encourages assistants to reuse an established UI kit and explain design decisions, states, and implementation constraints. The right level of detail depends on the task and the context you provide.

See [Skills](/docs/guides/skills) for design-system and handoff guidance, and [Your first task](/docs/first-task) for an example request.
