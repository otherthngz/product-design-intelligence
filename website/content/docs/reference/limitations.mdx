---
title: Limitations
description: Understand what PDI can and cannot guarantee.
---

PDI is a set of instructions and examples, not an AI model or an automatic design system. The assistant supplies its own reasoning, tools, permissions, and skill discovery.

- An installer can create host files; compatibility and automatic skill discovery have not been verified across every assistant.
- A response is not evidence that research, accessibility testing, or a real-world action occurred. Ask what was actually checked.
- Working modes describe guidance, not access controls, formal approval workflows, or compliance certification.
- PDI does not replace human judgment, real user research, or reviews appropriate to your project.

You remain responsible for reviewing the output and deciding what to ship. For agent-readable documentation, see [llms.txt](/llms.txt).
