# Glossary

- **Agent:** software that uses a model and tools to carry out a request.
- **Skill:** a folder of instructions the agent loads for a particular kind of task.
- **Evidence:** information with a traceable source; an assumption is an unverified working belief and a hypothesis is a claim to test.
- **Prototype:** a working representation used to explore an idea; it may simulate behavior and omit a backend.
- **Handoff:** the information a builder needs to implement and verify a design.
- **Adapter:** a mapping between PDI's tool needs and a host's actual capabilities. This repository documents a contract; it does not ship a general adapter runtime.
- **Validation:** checks actually performed. It is not the same as proving a design is usable or accessible for everyone.
